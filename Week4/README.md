# Week 4 – Predictive Modeling and Optimization in Logistics Systems

This project predicts logistics shipping time and demonstrates constrained resource allocation.

Methods: Random Forest Regression, train/test split, MAE, RMSE, R², 5-fold cross-validation and linear programming.

Files:
- data/logistics_week4_dataset.csv
- src/predictive_modeling_optimization.py
- reports/Week_4_Predictive_Modeling_and_Optimization_Report.docx

The dataset is synthetic and intended for educational use.
